# 수산물 가격 비교 운영 안내

## 화면 확인

상단 ‘새우 / 전어 / 방어’를 선택한 뒤 ‘시·도’에서 서울특별시·경기도·부산광역시를 선택합니다. 현재 확인된 자료는 기존 서울 새우 네 건입니다. 다른 조합은 빈 상태가 맞습니다. 가격 제보는 여전히 저장/전송 없는 미리보기입니다.

## 정보 구조

- `src/domain/seafood.ts`: 어종 설정, Seller(판매처), SeafoodProduct(상품), PriceRecord(가격 기록), SeafoodRepository(연결/조회), PriceComparison(비교).
- `src/data/seed.ts`: 기존 자료. 가게 하나에 여러 상품을 연결할 수 있고 가격 변경은 새 기록으로 추가합니다.
- `src/shops.ts`: 기존 지도/화면에 연결하는 얇은 변환층.
- `src/collectors/naver.ts`: PriceSource 인터페이스를 구현한 NaverBlogCollector. 허용된 SNS 경로가 마련되면 같은 인터페이스로 추가합니다.

새 어종은 seafoodCatalog에 고유 id, 표시 이름, 활어 표시 이름, 검색어를 추가하면 화면과 검색 도구가 함께 사용합니다. 가격은 sellerId와 productId로 연결합니다. 새 판매처의 marketId는 반드시 markets에 등록하고 시장에는 실제 region/district/address를 기록합니다. 주소·연락처·택배/방문 가능 여부를 추측하지 않습니다.

## 가격 기준

금액과 실제 중량이 모두 확인돼야 1kg 환산이 가능합니다. 마리·팩·상자 무게를 모르면 weightGrams는 null입니다. 종류·원산지·상태·크기가 모두 알려진 동일 조건 그룹 내에서만 가격을 정렬합니다. 미확인 조건은 그룹 비교나 시장 최저가 범위에 넣지 않습니다.

가격 이력은 삭제하지 않고 보존합니다. 공개 대표 기록은 검토 완료 기록 중 확인 시각(observedAt), 없으면 글 작성일(publishedAt)을 기준으로 최신을 고릅니다. 작성일을 실제 구매일로 바꾸지 않습니다. 날짜가 없는 자료는 날짜가 있는 최신 자료를 덮어쓰지 않습니다. 날짜가 모두 없거나 같으면 먼저 등록한 기록을 대표로 유지하므로 재확인 날짜를 입력해야 갱신됩니다.

## 네이버 검색 준비

이 도구는 블로그 검색 공식 API를 사용합니다. 원문 전체·확정 가격을 받는 기능이 아닙니다.
공식 안내: https://api.ncloud-docs.com/docs/naver-api-hub-search-blog

2026-07-31부터 기존 개발자센터의 검색 신규 신청은 중단됐습니다. 네이버 클라우드 콘솔 > Application Services > NAVER API HUB에서 이용 신청 후 블로그 검색 Application을 등록해야 합니다. 요금과 사용 한도를 확인하고 신청합니다. 프로젝트의 `.env.collector.local`에 다음 두 값을 넣습니다. 실제 키는 대화나 공개 소스에 적지 않습니다.

```
NAVER_CLIENT_ID=발급받은_아이디
NAVER_CLIENT_SECRET=발급받은_시크릿
```

`VITE_` 접두사를 붙이지 마세요. Node 수집 명령에서만 읽습니다. `.env.collector.local`은 제외 목록에 있습니다. Node 22.23 이상과 기존 프로젝트 의존성이 필요합니다.

```
npm run collect -- shrimp
npm run collect -- gizzard-shad 서울특별시,경기도
npm run collect -- yellowtail 부산광역시
```

검색 결과는 `outputs`에 매번 고유한 이름의 JSON과 HTML로 저장합니다. HTML을 열고 원문 링크를 눌러 확인할 수 있습니다. 키가 없으면 안내와 함께 종료합니다. 검색당 최대 30건, 어종의 각 검색어/지역별 최신순 요청이며 광범위한 전체 수집을 보장하지 않습니다. HTTP 오류/시간 초과 시 종료하고 부분 결과는 공개하지 않습니다.

## 후보를 가격 자료로 반영하는 과정

검색 지역은 검색어일 뿐 판매처 실제 주소가 아닙니다. 요약에 ‘1kg 30,000원’이 있어도 옵션/구매 시점/활어 여부가 다를 수 있습니다. 다음을 원문이나 매장으로 확인한 뒤 기록합니다.

1. 판매처 이름·주소·시장 내 위치와 해당 어종 판매 여부.
2. 활어/냉장/냉동/회 상태, 종류·원산지·크기.
3. 실제 금액·중량·추가 비용과 가격을 확인한 날짜.
4. 방문 구매·택배 가능 여부와 공개 연락처.
5. 원문 링크·글 작성일·확인 방법.

확인한 판매처/상품/가격을 seed에 추가하고 reviewStatus를 reviewed로 둡니다. 검색 후보는 candidate라서 공개 목록에 자동 들어가지 않습니다. 브라우저용 관리자/공유 저장소/자동 공개 기능은 이번 범위에 없습니다.
