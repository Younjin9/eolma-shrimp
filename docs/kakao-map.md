# 카카오지도와 가격 말풍선

## 화면 구성

- 성일수산, 부부전복(동작구), 영재수산(송파구), 흥한수산(강서구)을 등록했습니다.
- 시장 주소를 Kakao Geocoder로 확인해 시장 단위 말풍선을 표시합니다. 개별 점포의 실내 좌표는 추정하지 않습니다.
- 말풍선에는 등록된 kg 가격 범위, 시장 이름, 가게 수를 표시합니다. 누르면 가게별 가격과 확인/글 날짜가 펼쳐집니다.
- 말풍선의 가격은 이 앱에서 관리합니다. 외부 카카오맵을 열면 이 앱의 가격 말풍선은 함께 전송되지 않습니다.
- 키가 없거나 지도 로딩이 실패하면 실제 지도로 오해하지 않도록 가격 말풍선 미리보기를 표시합니다.

## 설정

1. [Kakao Developers](https://developers.kakao.com/)에서 앱을 만들고 카카오맵 사용 설정을 확인합니다.
2. JavaScript 키의 SDK 도메인에 실제 미리보기 주소와 배포 주소를 등록합니다. 로컬 실행은 실제 사용 중인 주소(예: `http://localhost:8443`)도 등록합니다.
3. 프로젝트 루트의 `.env.local`에 `VITE_KAKAO_MAP_APP_KEY=발급받은_JavaScript_키`를 저장합니다. `.env.example`을 참고하세요. REST API 키나 Admin 키가 아닙니다.
4. 개발 서버를 재시작하거나 배포 환경에서 같은 환경변수를 설정한 뒤 다시 빌드합니다. Vite 환경변수는 빌드에 포함되므로 JavaScript 키는 브라우저에 공개되며, 도메인 제한을 설정해야 합니다.
5. 세 시장의 지도 위치, 말풍선 클릭, 구/시장 필터, 화면 크기 변경을 확인합니다.

## 데이터 기준

- 성일수산: 사용자 제보, 2026-09-25 확인, 활새우 1kg 40,000원.
- 영재수산: 2026-09-21 후기, 1kg 31,000원. 일부 협찬. 9/20 다른 글은 32,000원. 방문일 미확인.
- 흥한수산: 다이닝코드 블로그 발췌, 9/14 표시, 1kg 35,000원. 연도와 방문일 미확인이라 최신 가격으로 분류하지 않습니다.
- 부부전복: 다이닝코드 블로그 발췌, 제목에 2026년 7월 시세, 7/17 표시, 1kg 40,000원. 방문일 미확인.
- 원산지·크기·세부 품종과 포장/손질비는 확인 전까지 미확인으로 둡니다. 전화번호도 근거가 확인된 가게에만 연결합니다.
- 가격 제보 양식은 기존 목업입니다. 저장·전송 서버가 없다는 안내를 표시합니다.
