# 얼마새우

서울·경기·부산의 활새우 판매처 가격을 비교하는 웹앱입니다. 현재 서울 7곳, 경기 2곳, 부산 1곳을 표시합니다.

가격은 사용자 제보·판매자 공지·후기 기준입니다. 실시간 가격이나 재고를 보장하지 않습니다. 종류·원산지·크기가 미확인인 상품은 동일 품질 최저가로 순위를 매기지 않습니다. 부산 지민수산은 온라인 주문 후 방문 수령 가격입니다.

## 실행

Node.js 22.12 이상에서 `npm ci`, `npm run dev`를 실행하세요. `npm test`, `npm run typecheck`, `npm run build`로 확인합니다.

## 지도

카카오 JavaScript 키를 Vercel 설정에 `VITE_KAKAO_MAP_APP_KEY`로 등록하고, 실제 배포 도메인을 카카오 개발자 콘솔에 허용해야 합니다. 키가 없으면 지도 미리보기와 판매처 목록을 보여줍니다. 네이버 Client Secret은 브라우저용 설정에 넣으면 안 됩니다.

## 가격 수집

네이버 출입증은 로컬 `.env.collector.local` 파일에만 보관합니다. `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`을 설정하고 `npm run collect -- shrimp`를 실행합니다. 검색 결과는 `outputs/`에 보관하며 검토 전에는 앱에 게시하지 않습니다. 현재 공개 웹앱에서 자동 수집을 실행하는 기능은 없습니다.

가격 제보 양식은 미리보기이며 아직 정보를 저장하지 않습니다. 운영 상세는 `docs/seafood-data.md`를 확인하세요.

형제수산은 생새우 후기 가격이며 활 상태·정확한 후기 날짜는 미확인입니다. 확인된 활새우와 같은 품질로 비교하지 않습니다.
